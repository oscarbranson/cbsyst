# Installation

## Requirements

- Python 3.7+
- NumPy
- SciPy
- Pandas

## Install from PyPI

```bash
pip install cbsyst
```

## Install from Source

```bash
git clone https://github.com/your-username/cbsyst.git
cd cbsyst
pip install -e .
```

## Development Installation

```bash
git clone https://github.com/your-username/cbsyst.git
cd cbsyst
pip install -e .[dev]
```
